RolidSCP is a fast two-panel file manager for local disks and remote servers over SFTP, inspired by WinSCP and Total Commander, written in Rust and native on Linux.

**This is a beta release.** It is used daily by its author, but expect rough edges. Please report bugs in Issues. Security problems should be reported privately, see [SECURITY.md](https://github.com/MrRolid/RolidSCP/blob/main/SECURITY.md).

## New in 0.8.20: polish

The last release of the 0.8 series adds no new features. It finishes and checks what is there: the keyboard and screen readers, damaged settings, two windows at once, and how the releases themselves are built and checked.

### In the window

- **The remaining time is calm.** It counts down by itself and never goes up because of a short drop in speed. When the line stops for 10 seconds or more, it shows that the time is unknown and waits. Replayed on the recordings of 0.8.19's outages, it went up 0 to 3 times instead of 94 to 304 times, and was 2 to 3 times closer to the real time. While uploading 110 GiB at full speed it was within 5 % at every quarter. After a real change of speed it takes one to three minutes to catch up. That is the price of a number that does not jump.
- **The menu bar by keyboard:** **F10** opens it, the arrows move through the menus and submenus, **Enter** chooses, **Esc** closes. Settings, About, favorites, checksums, the external editor, the master password and the log no longer need the mouse.
- **Screen readers (Orca)** now hear the folder list: its name, the item under the cursor (name, size or "folder", marked or not), and the names of the buttons and dialogs. Before, they heard unnamed items and the private-area characters of the icons. Without a screen reader nothing changes.
- **Long translations:** the function-key bar at the bottom keeps the labels that fit instead of dropping all of them (French, Polish, German and Spanish at 1280 px). The 22 dialogs were looked through in German, French and Polish, and at 100, 125, 150 and 200 % scale, with no text cut off.
- **Symbols without system fonts:** the sort arrow, the plus of the tabs, and the disk and info signs come from the program's own icons. A system without any fonts no longer shows empty boxes. A test checks that every character of the texts, translations and help has a glyph.
- **The transfer error summary** is a dialog like the others (Close, Esc). The panel behind it no longer takes Esc or F5.
- Checked under X11 and under Wayland (Weston at scale 1 and 2), and at 1.25×, 1.5× and 2× on X11.

### Times, ACLs and extended attributes

- **Zip times are right in every time zone.** A zip packed by RolidSCP now carries each file's time in UTC to the second (as Info-ZIP does), and reading prefers it. Before, a zip packed in one time zone and unpacked in another was off by the difference of the zones, and odd seconds were rounded. Checked across tools: packed in New York and unpacked by `unzip` in Kolkata, and the other way round, the times are exact. A zip time that falls in the gap of a daylight-saving change is no longer lost; it is read as an hour later.
- **What a copy keeps** is now written in the help: the file contents, the permission bits and the time are kept. The owner, setuid/setgid, ACLs, extended attributes and hard links are not. SFTP cannot carry ACLs or extended attributes at all. Keeping them for local copies is planned for 0.9.
- "Overwrite only older" compares the times in UTC, so time zones do not matter.

### Settings that survive

- **Two copies of the program at once** no longer lose each other's changes. Before, the copy that saved last wrote its servers and settings over the other's: of two copies each adding 40 servers, all of one copy's servers were lost. Now each save merges what the other copy changed meanwhile. Servers are merged one by one, and where both changed the same value, the later change wins. A change of the language or speed limit in one window reaches the other within 3 seconds. The saved passwords are merged too. A change of the master password in another window is reported, never overwritten.
- **A damaged settings file costs only what is damaged.** Before, one typo in `profiles.toml` loaded an empty list, and the next save wrote it over the file, so every server was lost. Now the file is first kept as `<name>.damaged`. Then a broken line (a quote left open, a cut-off end) is left out, and the rest is read value by value. A server with a broken port costs that server; a tab of an unknown kind costs that tab. The line at the bottom of the window says what was left out.
- **Going back to an older version and returning keeps the settings.** Values that this version does not know (from a newer version) stay in the files when it saves them. The settings of every version from 0.1 to 0.8.19 are read without loss, and going back from 0.8.20 to 0.8.13–0.8.19 loses nothing.
- A log over 2 MB is kept as `rolidscp.log.old` instead of deleted. The first line of each start names the process, so two copies can be told apart.

### Checked on every build

- **Fuzz testing** of everything the program reads from outside: archives (zip, 7z, tar, tar.gz, tar.zst, plain and encrypted), server listings and the output of `du`, `df`, `find`, `smartctl` and checksum tools, `known_hosts`, `/proc/self/mountinfo`, texts in every encoding of the viewer, and damaged pictures. A few hundred damaged inputs per target on every build; before the release, 200 000 per target (2 million for the parsers), with integer overflow checks on. It found one crash, now fixed: an impossible time (`inf`, `1e300`) in a remote search result ended the program. Nothing unpacked from a damaged archive is ever written outside the target folder.
- **Licences, sources and security advisories of all dependencies** with `cargo deny`. Every licence is compatible with GPL-3.0-or-later, and everything comes from crates.io. The `url` library was updated for an advisory. One advisory without a fix (`rsa`, through the SSH library, where the key only signs the login) is accepted with a reason. The code was also compared with the sources of all 904 libraries in the local cache: nothing was taken over.
- **Performance:** a load test with 10 000 files on every build, compared with the build before. It covers listing a local and an SFTP folder, folder sizes, searching, memory, a deep tree, copying and deleting, frame times in the real window, and the same work done with standard tools.

### Releases you can check

- **Signed checksums:** `SHA256SUMS.asc` is the OpenPGP signature of `SHA256SUMS`, made with the release key published in the repository ([`docs/release-key.asc`](https://github.com/MrRolid/RolidSCP/blob/main/docs/release-key.asc)).
- **Reproducible packages:** the same commit gives the same `.deb`, `.rpm` and AppImage, byte for byte. Every time inside is the time of the commit, and no path of the build machine is in the binary. A second CI job builds everything again on another machine in another folder, and a release is made only when the two builds are the same.
- **AppImage update:** updating with AppImageUpdate from 0.8.19 was checked against this release's `SHA256SUMS`. When a changed copy of an AppImage was repaired the same way, only the changed 4 KiB were downloaded.

## Requirements

- Linux on 64-bit x86 (amd64 / x86_64) with glibc 2.35 or newer: Debian 12 and newer, Ubuntu 22.04 and newer, current Fedora, openSUSE Leap and Tumbleweed, or another distribution with the AppImage
- X11 session recommended (drag and drop to and from other applications is not available on Wayland)

## Known problems

- A server that refuses a second SFTP channel gets folder listings through the library's own path, which has no limit on the number of entries.
- Sparse files lose their holes when copied.
- ACLs and extended attributes are not copied (planned for 0.9), and a server whose clock is off gives its files wrong times in the panel; there is no warning yet (0.9).
- The context menus (tab color, "Close other tabs") need the mouse; Shift+F10 and the Menu key are planned for 0.9.
- Not tested yet: a Windows server and a NAS.

## Install

Check the downloads first. With the release key, the signature and the checksums in one folder:

```sh
gpg --import release-key.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum -c --ignore-missing SHA256SUMS
```

- Debian, Ubuntu, Linux Mint: `sudo apt install ./rolidscp_0.8.20_amd64.deb`
- Fedora: `sudo dnf install ./rolidscp-0.8.20-1.x86_64.rpm`
- openSUSE: `sudo zypper install --allow-unsigned-rpm ./rolidscp-0.8.20-1.x86_64.rpm`
- Other distributions: `chmod +x RolidSCP-0.8.20-x86_64.AppImage` and run it (needs FUSE). The AppImage of 0.8.19 updates itself to this one with AppImageUpdate (`appimageupdatetool RolidSCP-0.8.19-x86_64.AppImage`).
