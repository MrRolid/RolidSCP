RolidSCP is a fast two-panel file manager for local disks and remote servers over SFTP, inspired by WinSCP and Total Commander, written in Rust and native on Linux.

**This is a beta release.** It is used daily by its author, but expect rough edges. Please report bugs in Issues. Security problems should be reported privately, see [SECURITY.md](https://github.com/MrRolid/RolidSCP/blob/main/SECURITY.md).

## New in 0.8.17: bad connections

### The path above a panel

- **Every part of the path is a button.** A click opens that folder, on this computer, on a server and inside an archive (the part of an archive's folder leaves the archive); the cursor lands on the folder you came from. The **middle button** opens the folder in a new tab next to the current one. The part under the mouse is highlighted.
- A path too long for the row is **shortened from the left** with “…”, which opens the drop-down of the whole path; the last part always stays whole.
- To type a path: **double-click the empty part of the row**, click the **pencil** at its end, or press **Ctrl+G**. A single click on the row no longer starts editing.
- The icons of the bar above the panels (Back, Forward, Up one level, Root folder, Home folder, Refresh, Favorites) are **bigger and in color**, drawn sharp on whole pixels. The bar grew by 2 pixels.

### Marking by a mask

- The **Num+** and **Alt+−** dialogs remember the last mask and whether **Include folders** is on, each for itself and also after a restart.
- On a server marked as **production**, Include folders is always off when the dialog opens, and the choice made there is not remembered.

### What was tested, and how

- **A bad line, for real:** a local OpenSSH server in a private network namespace (no root needed), its line made bad with the kernel's network emulator. A 32 MiB file and a folder of 200 small files went to the server and back through the program's own copy code, with the program's keepalive, reconnection and resume, and **every file was compared by SHA-256**.
- **Killed while packing and extracting, 60 times:** no damaged archives or files, and every unfinished `.filepart` file was cleaned up.

### Fixes

- **A slow line no longer drops a working connection.** The program asked for up to 16 MB ahead with a 30-second limit per request, so on every line slower than about 0.5 MB/s the last answer came "too late" and the connection was dropped and made again, over and over. Now 4 MB ahead and 90 seconds; a dead connection is still noticed by the keepalive within 45 seconds.
- **A transfer goes on as long as it gets further.** The five automatic continuations after a lost connection counted every drop-out of the whole transfer; now they count drop-outs in a row without progress, so a long transfer over a line that keeps breaking finishes.
- **A file continued several times is counted once**: the window no longer shows, for example, 29 MB done of an 8 MB file.
- **A pack or extract killed in the middle** no longer leaves its unfinished `.filepart` file: the program notes the file while writing it and deletes what a killed run left at the next start.
- **The quick filter** in a folder of a million files: the first key now takes about 30 ms instead of 0.1–0.3 s, and clearing the filter is as fast.
- Backspace in the quick filter no longer loses key presses when typed quickly.
- **The news** in the About window are translated into all eight languages.

### Known problems

- Downloading over a line with a long round trip is slower than OpenSSH's `sftp` (24 s against 9.5 s for 32 MiB at 100 ms); uploading is as fast. This was the same in 0.8.16.
- A line that is down for 30 seconds and up for only 8, again and again, is not survived: the transfer keeps reconnecting without getting far. OpenSSH's `sftp` gives up on such a line too.
- Sparse files lose their holes when copied.
- The test with a real file over 100 GB, the overnight transfer and the computer going to sleep during a session were not done; they move to 0.8.18 (see the [roadmap](https://github.com/MrRolid/RolidSCP/blob/main/ROADMAP.md)).

## Requirements

- Linux on 64-bit x86 (amd64 / x86_64) with glibc 2.35 or newer: Debian 12 and newer, Ubuntu 22.04 and newer, current Fedora, openSUSE Leap and Tumbleweed, or another distribution with the AppImage
- X11 session recommended (drag and drop to and from other applications is not available on Wayland)

## Install

Check the downloads with `sha256sum -c --ignore-missing SHA256SUMS`, then:

- Debian, Ubuntu, Linux Mint: `sudo apt install ./rolidscp_0.8.17_amd64.deb`
- Fedora: `sudo dnf install ./rolidscp-0.8.17-1.x86_64.rpm`
- openSUSE: `sudo zypper install --allow-unsigned-rpm ./rolidscp-0.8.17-1.x86_64.rpm`
- Other distributions: `chmod +x RolidSCP-0.8.17-x86_64.AppImage` and run it (needs FUSE)
