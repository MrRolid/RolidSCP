RolidSCP is a fast two-panel file manager for local disks and remote servers over SFTP, inspired by WinSCP and Total Commander, written in Rust and native on Linux.

**This is a beta release.** It is used daily by its author, but expect rough edges. Please report bugs in Issues. Security problems should be reported privately, see [SECURITY.md](https://github.com/MrRolid/RolidSCP/blob/main/SECURITY.md).

## Highlights

- Two panels with tabs, local and remote on either side, server-to-server transfers
- SFTP with password, key and keyboard-interactive login, automatic reconnect and resume of interrupted transfers
- Saved passwords in an encrypted vault protected by a master password (Argon2id, XChaCha20-Poly1305), with automatic locking
- Edit remote files in your own editor (F4) with automatic upload and conflict detection
- Built-in viewer (F3): text with syntax highlighting, hex view, images, fast search in very large files
- Archives: pack and unpack zip, 7z, tar, tar.gz and tar.zst, browse archives like folders
- Drag and drop from and to other applications (X11)
- Folder sizes, checksums, bookmarks, selection by mask, history, terminal at the current folder (Ctrl+P)
- Free space and disk health (SMART) for local disks
- Available in English, Czech, German, French, Polish, Spanish, Norwegian and Danish

## New in 0.8.13

- Listings refresh automatically: local folders are watched live, remote folders refresh after your own operations, when you return to the panel, and at a configurable interval
- Resizable columns with separators, widths are remembered per panel
- Disk health shown as a compact icon that turns orange or red when a threshold is crossed
- Files created with Shift+F4 update their size in the panel after saving
- Fixed dragging remote files to Thunar and other file managers
- Fixed a case where an operation could hang for 30 seconds when the connection dropped

## Requirements

- Linux, amd64, Debian or Ubuntu based distribution
- X11 session recommended (drag and drop to other applications is not available on Wayland)

## Install

Download `rolidscp_0.8.13_amd64.deb` below and run:

    sudo apt install ./rolidscp_0.8.13_amd64.deb
