RolidSCP is a fast two-panel file manager for local disks and remote servers over SFTP, inspired by WinSCP and Total Commander, written in Rust and native on Linux.

**This is a beta release.** It is used daily by its author, but expect rough edges. Please report bugs in Issues. Security problems should be reported privately, see [SECURITY.md](https://github.com/MrRolid/RolidSCP/blob/main/SECURITY.md).

## New in 0.8.18: servers and distributions

### Connections that keep breaking

- **A dead connection is noticed in 15 seconds.** When nothing comes from the server for 15 seconds while the program waits for it, the connection is taken as dead and made again at once. After 5 seconds of silence the program asks the server for a short answer, so a slow server that still answers is not mistaken for a dead line.
- **Reconnecting is tried every few seconds in the first three minutes** after a drop-out (1, 2, 3 s…), then every 10 seconds, and every 30 seconds after ten minutes. Each attempt tries a new network connection every 4 seconds.
- **An upload continues from the part the server confirmed.** The program counts what the server acknowledged, so after a drop-out only the unconfirmed rest is sent again (when that is not known, the last 2 MiB instead of 4 MB).
- A line that is **down for 30 seconds and up for only 8, again and again**, is now survived: the file and the folder of small files arrive whole. OpenSSH's `sftp` does not finish on that line.

### Downloads over a distant line

- **About twice as fast.** The SSH library's window of 2 MB held a download back to 1–2 MB per round trip; it is now 8 MiB. A download of 32 MiB at 100 ms now takes 6.5 s, against 9.8 s for OpenSSH's `sftp` (0.8.17: 24 s).

### Faulty and hostile servers

- A server cannot make the program **write outside the target folder**: names with `/`, `..` or nothing in them are refused, control characters in names are shown as `\xNN`, and a link pointing outside the target folder never leads a copy out of it.
- A **folder listing that does not end** is stopped after 5 million entries, with an error instead of filling the memory.
- A **file the server sends far past its size** (by more than its own size, or by more than 64 MiB for a small file) is stopped and nothing of it is kept.
- A server that **stops answering** in the middle of a listing or transfer is noticed (see above) instead of the program waiting for ever.

### The AppImage on minimal systems

- The AppImage now **carries the libraries a minimal system may lack** (libxkbcommon, libxkbcommon-x11, the X11 cursor and input libraries, the Wayland cursor and EGL libraries) and uses each only where the system has none of its own; nothing else on the system, and no program started from RolidSCP, sees them. Where the keyboard data folder is missing, an empty one stands in. Before, the AppImage ended within seconds without a window on such a system (found by the AppImage catalog's test).
- **A start that fails shows its error in a window** (zenity, kdialog, or a plain window of its own), for example when no graphics driver is installed. Before, it ended silently.

### What was tested, and how

- **Servers, without a physical machine:** each started from a distribution image in a user namespace, without root, and tested through the program's own code: connecting, listing, a file and a folder up and back compared by SHA-256, links, times, F4 (replacing a file with its permissions), permissions of a file and a folder, renaming, replacing, deleting, packing to the server and extracting, free space, folder sizes, search, and the server tools.
- **The packages in other distributions:** each installed with the distribution's own package manager and the program's window driven with the keyboard on a virtual screen against an SSH server: a folder down and up compared by SHA-256, a new folder on the server, packing onto the server (the archive's content compared), deleting there. The AppImage in every distribution too.
- **A hostile server:** an SFTP server written for the test that lies about sizes, sends names with `..`, `/` and control characters, links outside the target folder, a listing of 300 000 entries, one that never ends, a file that never ends, and stops answering.
- **The bad-line test of 0.8.17 again,** now next to OpenSSH's `sftp` on the same line, and the AppImage on a minimal Ubuntu 22.04 without network on every build.

The scripts are in [`scripts/compat`](https://github.com/MrRolid/RolidSCP/tree/main/scripts/compat) (`servers.sh`, `distros.sh`, `gui-scenario.sh`) and [`scripts/bench`](https://github.com/MrRolid/RolidSCP/tree/main/scripts/bench) (`badnet.sh -r`). ### Fixes

- The program **no longer waits up to 90 seconds** for a server that stopped answering in the middle of an operation other than a transfer (a listing, a rename): every operation is watched the same way.

### Known problems

- A server that refuses a second SFTP channel gets folder listings through the library's own path, which has no limit on the number of entries.
- On a system without any fonts, a few symbols of the window (the sort arrow, the plus of the tabs, the disk and info signs) are missing; planned for 0.8.19.
- Sparse files lose their holes when copied.
- Not tested yet, on a separate test machine later: a real file over 100 GB, a transfer running overnight, the computer going to sleep during a session, a network cable pulled out, a Windows server and a NAS (see the [roadmap](https://github.com/MrRolid/RolidSCP/blob/main/ROADMAP.md)).

## Requirements

- Linux on 64-bit x86 (amd64 / x86_64) with glibc 2.35 or newer: Debian 12 and newer, Ubuntu 22.04 and newer, current Fedora, openSUSE Leap and Tumbleweed, or another distribution with the AppImage
- X11 session recommended (drag and drop to and from other applications is not available on Wayland)

## Install

Check the downloads with `sha256sum -c --ignore-missing SHA256SUMS`, then:

- Debian, Ubuntu, Linux Mint: `sudo apt install ./rolidscp_0.8.18_amd64.deb`
- Fedora: `sudo dnf install ./rolidscp-0.8.18-1.x86_64.rpm`
- openSUSE: `sudo zypper install --allow-unsigned-rpm ./rolidscp-0.8.18-1.x86_64.rpm`
- Other distributions: `chmod +x RolidSCP-0.8.18-x86_64.AppImage` and run it (needs FUSE)
