RolidSCP is a fast two-panel file manager for local disks and remote servers over SFTP, inspired by WinSCP and Total Commander, written in Rust and native on Linux.

**This is a beta release.** It is used daily by its author, but expect rough edges. Please report bugs in Issues. Security problems should be reported privately, see [SECURITY.md](https://github.com/MrRolid/RolidSCP/blob/main/SECURITY.md).

## New in 0.8.15: many files

This release was tested with a folder of a million files, a tree of a million small files copied to a local SFTP server and back, and a folder tree 1000 levels deep. The measurements and the scripts that make them are in [`scripts/bench`](https://github.com/MrRolid/RolidSCP/tree/main/scripts/bench).

Measured on the author's machine (20 threads, ext4, OpenSSH server on 127.0.0.1), a folder with 1 000 000 files:

| | 0.8.15 | Limit |
|---|---|---|
| Local folder listed and shown in the window | 3.1 s (before: 13.7 s) | ≤ 10 s |
| Same folder over SFTP | 26 s | ≤ 60 s |
| Scrolling, longest frame | 4.4 ms | ≤ 50 ms |
| Sorting, slowest column | 0.7 s | ≤ 1 s |
| Quick filter, one key | 0.16 s (before: 0.61 s) | ≤ 0.2 s |
| Copying 1 000 000 files of 1 kB to the server / back | 12.5 / 15.2 min (`sftp put -r`: 39 min, `get -r`: 52 min) | ≤ 2 × sftp |
| Deleting them locally / on the server | 38 s / 2.9 min (`rm -rf`: 26 s, `sftp rm`: 25 min) | ≤ 2 × reference |
| Memory with the folder open | 571 MB | ≤ 1 GB |

Marking all items with Ctrl+A in such a folder still takes about 0.7 s.

- **Copying many small files** to and from a server is much faster: the target folder is listed once instead of checking every file, and small files are sent several at a time. A file that appears under the same name during the copy is still never overwritten against your choice.
- **Folder listings over SFTP** of big folders are much faster (the listing no longer slows down with every batch the server sends).
- **Deleting** runs in the transfer queue with the number of deleted items and can be canceled; on a server several files are deleted at a time.
- **Big folders** sort, filter and refresh in the background without stalling the window; the panel footer and marking all items stay fast with a million entries.
- **Pipes, sockets, devices and broken links** are skipped and reported at the end. Before, copying a pipe waited forever and a broken link stopped the whole copy.
- **Unusual names** are copied exactly and shown on one line: names with a backslash, line breaks, a leading dash or 255 bytes (copying such a name failed before), and on local disks also names that are not valid UTF-8 (shown as `\xFF`; they cannot be sent to a server and this is reported).
- **Very deep folder trees** (over 1000 levels) no longer crash the program.
- Search by name, folder sizes and checksums on a server use commands on the server again instead of the slow walk over SFTP (broken in 0.8.14).
- An error of an SFTP server is no longer said twice ("Permission denied: Permission denied").

## Requirements

- Linux on 64-bit x86 (amd64 / x86_64) with glibc 2.35 or newer: Debian 12 and newer, Ubuntu 22.04 and newer, current Fedora, openSUSE Leap and Tumbleweed, or another distribution with the AppImage
- X11 session recommended (drag and drop to and from other applications is not available on Wayland)

## Install

Check the downloads with `sha256sum -c --ignore-missing SHA256SUMS`, then:

- Debian, Ubuntu, Linux Mint: `sudo apt install ./rolidscp_0.8.15_amd64.deb`
- Fedora: `sudo dnf install ./rolidscp-0.8.15-1.x86_64.rpm`
- openSUSE: `sudo zypper install --allow-unsigned-rpm ./rolidscp-0.8.15-1.x86_64.rpm`
- Other distributions: `chmod +x RolidSCP-0.8.15-x86_64.AppImage` and run it (needs FUSE)
