RolidSCP is a fast two-panel file manager for local disks and remote servers over SFTP, inspired by WinSCP and Total Commander, written in Rust and native on Linux.

**This is a beta release.** It is used daily by its author, but expect rough edges. Please report bugs in Issues. Security problems should be reported privately, see [SECURITY.md](https://github.com/MrRolid/RolidSCP/blob/main/SECURITY.md).

## New in 0.8.14: data protection

- **Production servers:** copying (F5, dragging between panels), files dropped from another application, moving and creating a folder can no longer be confirmed with Enter, the dialog is red as for deleting, and copying or moving never starts with *Overwrite* (*Skip existing* is preselected).
- **Moving:** a source file is deleted only when its size and modification time did not change during the transfer. The new option *Verify by checksum before deleting the source* (on by default for moves to a server and between servers) reads both files again and compares their BLAKE3 checksums first; a file that changed or whose copy differs stays in the source and is reported.
- **Resuming:** an interrupted transfer is resumed only from a `.filepart` of the same source file (its path, size and modification time are stored next to it). A part file of another or an unknown source is left untouched and reported; resuming never appends to the file under its real name.
- **Replacing files on servers without atomic rename:** the transfer queue never deletes the target first; the old file is moved aside, the new one put in place, then the old one deleted. The step is journaled locally, and a replacement cut off by a lost connection or a crash is finished or undone at the next connection.
- **F4 editing:** copies are kept on disk (`~/.local/state/rolidscp/edit`, private) instead of in memory, so saved edits that were not uploaded yet survive a crash or restart of the whole system; an upload that fails for another reason than a lost connection is tried again twice and then clearly reported; the time of the last upload is shown with seconds.
- Temporary names of a cut-off rename are now English (`.rolidscp-old`, `.rolid-renaming`); leftovers with the old names are still recognised.
- The program starts on a system without any system font, with its built-in fonts.
- Short check commands on a server (search, checksums, viewer search, file system type) give up after 5 seconds and fall back to SFTP, so a server whose shell hangs no longer holds them up.
- Zip archives: an empty file in a password-protected zip is stored instead of compressed, as 7-Zip does; p7zip 16.02 (Ubuntu 22.04) reported such entries as damaged although they were valid.

## Requirements

- Linux on 64-bit x86 (amd64 / x86_64) with glibc 2.35 or newer: Debian 12 and newer, Ubuntu 22.04 and newer, current Fedora, openSUSE Leap and Tumbleweed, or another distribution with the AppImage
- X11 session recommended (drag and drop to and from other applications is not available on Wayland)

## Install

Check the downloads with `sha256sum -c --ignore-missing SHA256SUMS`, then:

- Debian, Ubuntu, Linux Mint: `sudo apt install ./rolidscp_0.8.14_amd64.deb`
- Fedora: `sudo dnf install ./rolidscp-0.8.14-1.x86_64.rpm`
- openSUSE: `sudo zypper install --allow-unsigned-rpm ./rolidscp-0.8.14-1.x86_64.rpm`
- Other distributions: `chmod +x RolidSCP-0.8.14-x86_64.AppImage` and run it (needs FUSE)
